# Mission

## The Goal
To understand, maintain, and improve an inherited PostgreSQL database.

## Context
- The learner has inherited an existing PostgreSQL database (work context).
- They need to go from foundational understanding to practical competence.
- Key areas of interest include: SQL fundamentals, table naming conventions, database connections, and PostgreSQL best practices.

## Success Criteria
- Ability to read and understand the existing database schema and queries.
- Ability to write correct, idiomatic SQL for PostgreSQL.
- Ability to make improvements to the database with confidence.
